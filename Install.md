# Installation Prerequisites

## Required Software

- [ ] Rust toolchain (stable) — `rustup install stable`
- [ ] Scala JDK 2.13 — `sdkman install java 21.0.5`
- [ ] sbt — `sbt scripted` or `brew install sbt` (macOS) / `choco install sbt` (Windows)
- [ ] CMake — for any native dependencies
- [ ] git
- [ ] A C++17 compatible compiler (for any FFI bindings)
- [ ] A graphics driver with Vulkan support (for the GPU backend)
- [ ] A Windows/Linux/macOS build environment

## Optional but Recommended

- [ ] Visual Studio Code + Rust/Scala extensions
- [ ] Docker (for reproducible builds)
- [ ] CodeQL CLI (for security scanning)
- [ ] A GPU with Vulkan 1.3 support (for the GPU backend)
